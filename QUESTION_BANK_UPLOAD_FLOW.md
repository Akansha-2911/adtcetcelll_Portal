# Question Bank Upload Flow

Question Bank -> Upload Questions -> Scan Paper & Review -> classify reviewed questions -> Save to Question Bank.

Classification supported before scan and during review:
- Course (required): JEE / CET / NEET
- Subject (required)
- Topic (optional)
- Subtopic (optional)
- Difficulty
- Marks (required)

Review page also supports applying the same classification to all selected questions with the Bulk Classification panel.

The Question model now stores an optional course value for newly scanned questions while remaining compatible with existing Question Bank records.
